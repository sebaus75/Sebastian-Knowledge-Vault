# Obsidian - Gestion de Vault

Principios esenciales para administrar un vault de Obsidian.

## Principios Fundamentales
1. **Links sobre folders** - Los wikilinks remplazan jerarquias profundas
2. **Atomicidad** - Una nota = una idea
3. **MOC (Map of Content)** - Notas indice que agrupan y navegan contenido
4. **Tags para propiedades transversales** - NO para organizacion principal
5. **Flat structure** - Maximo 2-3 niveles de profundidad

## Ciclo de Vida de una Nota
1. Captura rapida en Inbox
2. Procesamiento semanal: clasificar, linkear, archivar
3. Nota permanente: idea unica, bien linkeada
4. Archivo: proyecto terminado o referencia pasiva

## Mantenimiento Regular
### Semanal
- Vaciar Inbox
- Revisar enlaces rotos
- Back up a GitHub

### Mensual
- Archivar proyectos completados
- Revisar tags no utilizados
- Correr Vault Inspector

## Plugins Recomendados
- Dataview - Consultas sobre metadatos
- Tag Wrangler - Gestion masiva de tags
- Vault Inspector - Salud del vault (enlaces rotos, huerfanos)
- Local Images Plus - Descarga y organizacion de imagenes
- Auto Note Mover - Automover notas basado en tags
- Plugin Update Tracker - Mantener plugins actualizados
