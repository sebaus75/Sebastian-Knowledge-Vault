# Zero Dependency Architecture

Enfoque de desarrollo que evita frameworks y librerias externas, usando solo APIs nativas del entorno (CDN, vanilla JS, serverless).

**Idea clave**: Menos dependencias = menor mantenimiento, cero vulnerabilidades de terceros, sin build step.
