# OpenAI - Overview

Fundada en 2015 por Sam Altman, Elon Musk, Greg Brockman, Ilya Sutskever y otros. Creadores de GPT, DALL-E, Sora.

## Hitos
- 2015: Fundacion (co-fundada por Andrej Karpathy)
- 2020: GPT-3
- 2022: ChatGPT, DALL-E 2
- 2024: GPT-4o, Sora
- 2025: OpenAI o1 (razonamiento), GPT-5
- 2026: Competencia directa con Anthropic y Google

## Ecosistema
- API de OpenAI (modelos GPT-4o, o1, o3)
- ChatGPT (producto consumer)
- Sora (generacion de video)
- OpenAI Codex (base de GitHub Copilot)
- DALL-E 3 (generacion de imagenes)

## Competencia
- Anthropic (Claude) - enfoque en seguridad y AI constitucional
- Google DeepMind (Gemini) - integracion con ecosistema Google
- Meta (Llama) -开源

## Nota
Andrej Karpathy, co-fundador de OpenAI, se unio a Anthropic en Mayo 2026 para trabajar en pre-training, senalando un cambio en la dinamica de talento en IA fronteriza.
