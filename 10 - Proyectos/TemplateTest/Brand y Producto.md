# Brand y Producto

## Propósito

Template landing page + admin panel de nivel comercial. Un producto genérico, adaptable a cualquier nicho de negocio (barbería, clínica, restaurante, gimnasio, despacho, etc.), que se vende como solución llave en mano a dueños de negocios que quieren presencia web profesional sin pagar mensualidades ni depender de agencias.

## Propuesta de valor

> Una landing page profesional con panel admin completo, 4 temas visuales, booking multi-paso, galería, reseñas, SEO y backend — por un pago único. Sin mensualidades, sin SaaS, sin limitaciones.

### Diferenciadores
- **Pago único, no suscripción**: El cliente paga una vez y es dueño del código
- **Sin dependencias**: No necesita agencia, no paga hosting mensual (Vercel gratis)
- **Backend gratuito**: Google Sheets como BD, Google Apps Script como API
- **Personalizable**: 4 temas + editor visual, sin tocar código
- **Zero mantenimiento**: Static site, no hay servidor que mantener

## Audiencia objetivo

Dueños de pequeños y medianos negocios locales que:
- No tienen página web o tienen una obsoleta
- Quieren profesionalismo sin pagar $10k+/mes a una agencia
- Usan WhatsApp como canal principal de comunicación con clientes
- Necesitan que los clientes puedan agendar citas online
- Quieren poder administrar su contenido ellos mismos

### Nichos primarios
| Nicho | Ejemplo |
|---|---|

| Clínicas dentales/médicas | Consultorios con agenda |

| Template + setup | Template + deploy Vercel + config GAS + personalización de marca | $45,000 MXN |

## Principios de diseño

1. **Genérico pero con personalidad** — El template debe verse bien con cualquier marca, no diseñado para un nicho específico
2. **Conversión primero** — Booking, WhatsApp y contacto son las acciones principales
3. **Admin empoderador** — El dueño del negocio debe poder cambiar todo sin saber código
4. **Mobile primero** — Los clientes buscan y agendan desde el celular
5. **Performance nativa** — Sin frameworks pesados, carga instantánea

## Anti-referencias
- No usar estilos sobrecargados o "template genérico"
- Evitar animaciones gratuitas que ralenticen la experiencia
- No depender de servicios de pago para funcionalidad core
- Evitar "template de agencia" con branding del creador
