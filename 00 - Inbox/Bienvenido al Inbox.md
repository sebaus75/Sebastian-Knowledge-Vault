# Bienvenido al Inbox

Esta carpeta es para **captura rapida** de ideas, notas sin procesar y pensamientos sueltos.

## Reglas
- Sin filtro: cualquier idea aqui
- Sin estructura: no importa el formato
- Fecha siempre visible en la nota
- Una nota por idea

## Procesamiento
Revisar esta carpeta **cada semana** (según VAULT.md):
1. Leer cada nota
2. Clasificar: ¿es un proyecto? ¿un recurso? ¿una nota atomica?
3. Mover a la carpeta correspondiente (10, 20, 30)
4. Si no es relevante, archivar o eliminar

## Flujo
```
Inbox (00) → Procesar semanalmente → Proyecto (10) / Area (20) / Recurso (30) / Archivo (40)
```
